# Assets Directory

Place your output screenshot images in this directory to display them automatically in your main `README.md`:

1. `input_vs_overlay.png` - Input image side-by-side with walkable area green overlay.
2. `realtime_navigation.png` - Real-time navigation window showing detected walkable areas and STOP sign indicator.
3. `output_pipeline.png` - 3-panel image showing Input RGB image, Predicted RGB Mask with Walkable Classes, and Binary Walkability Mask.
